# Concepts — Cordenar MCP

The Concepts feature indexes local markdown files as searchable concepts (skills, agents, instructions, workflows, references, knowledge bases). Supports frontmatter parsing, FTS5+vec0 hybrid search, and cloud sync.

**MCP tools:** concept_search, concept_search_context, concept_index, concept_deindex, concept_get, concept_family, concept_context, concept_list (8 tools).
