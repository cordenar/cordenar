# Dashboard — Cordenar MCP

The local web dashboard provides a UI for browsing, searching, and inspecting memories and concepts. It runs on `localhost:3458` and communicates with the MCP backend via a local HTTP API and SSE for real-time updates.

**MCP tools:** None (HTTP API, not MCP tools).
